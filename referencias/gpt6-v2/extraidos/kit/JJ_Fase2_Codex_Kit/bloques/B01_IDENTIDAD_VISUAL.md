# B01 | Identidad visual (prioridad máxima)
**Estado inicial:** PENDIENTE | **Dependencia:** B00 aprobado.
**Objetivo:** elegir una marca y un sistema de diseño distintivo, premium y utilizable en supermercado.

## Encargo a Codex
Basándote en `docs/DIRECCION_VISUAL.md`:
1. Crear una exploración de tres rutas visuales, con nombres, paletas y carácter: V1 Verde Esencial, V2 Verde Noche, V3 Verde Mercado. Usar el **mismo contenido realista** en las tres para comparación justa.
2. Para cada ruta, presentar **Inicio**, estado vacío de lista y navegación; etiquetas en español. No inventar precios de supermercados.
3. Crear 3 variantes originales del monograma «JJ» + denominación completa, y versiones icono de app, cabecera y monocromo. Evitar carrito genérico con hoja.
4. Estudiar tipografía, contraste, accesibilidad, espaciado, botones, iconos y lenguaje de ilustración/fotografía.
5. Si se necesitan cambios de código para renderizar el diseño, colocarlos en rama prototipo aislada y limitar el alcance al diseño; no implementar lógica de negocio.
6. Producir capturas legibles a tamaño iPhone y un cuadro de pros/contras. Explicar qué se puede implementar con activos/licencias existentes.

## Entregables
3 propuestas comparables + 3 opciones de marca + mini guía de estilos por propuesta + captura con lista vacía y lista poblada. Riesgos de cada una.

## Criterios de aprobación
- [ ] Los verdes tienen contraste comprobado.
- [ ] La interfaz tiene personalidad propia, sin copiar a Jowzi.
- [ ] Acción principal legible sin desplazamiento.
- [ ] Logo reconocible en tamaño pequeño y con fondo oscuro/claro.
- [ ] El usuario elige explícitamente una dirección y un logo.

**STOP:** no fijar diseño definitivo ni avanzar a B02 antes de selección.
