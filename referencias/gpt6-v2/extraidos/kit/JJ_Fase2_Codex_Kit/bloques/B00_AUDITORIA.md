# B00 | Auditoría del repositorio sin cambios
**Estado inicial:** BLOQUEADO (acceso al repo pendiente)
**Objetivo:** conocer exactamente el punto de partida y no perder código, datos ni decisiones existentes.
**Dependencias:** conexión Codex Cloud a GitHub y repositorio seleccionado.

## Tareas exclusivas para Codex
1. Identificar nombre completo, visibilidad, rama, historial reciente, README, estructura y archivos clave.
2. Determinar framework, versión, dependencias, entorno de ejecución, scripts y CI. Distinguir lo probado de lo supuesto.
3. Inventariar pantallas, recursos visuales y funcionalidades que ya funcionan.
4. Detectar problemas: build, test, secretos, costos, deuda técnica y conflicto de instrucciones existentes.
5. Generar informe «reusar / mejorar / investigar / descartar» por módulo, sin borrar nada.
6. Proponer cómo incorporar los documentos de este kit evitando sobrescrituras.
7. Proponer PRs secuenciales con estimación cualitativa de esfuerzo y riesgos. Proponer cómo obtener screenshots de iPhone.

## Entregables
Informe de diagnóstico, captura del estado visual real si la app es ejecutable, árbol de carpetas resumido, plan de integración documental y próximos pasos.

## Criterios de aprobación
- [ ] No se realizó ningún cambio de código ni commit.
- [ ] Está claro qué código ya existe y cuál puede reutilizarse.
- [ ] Se conocen pruebas ejecutables y posibles bloqueos.
- [ ] El siguiente bloque está definido como B01, nunca como desarrollo de pagos.

**STOP:** no empezar B01 sin aprobación del propietario.
