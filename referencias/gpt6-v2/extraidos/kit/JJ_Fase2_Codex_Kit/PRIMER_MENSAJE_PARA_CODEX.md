# Primera tarea para Codex: B00 | AUDITORÍA SIN MODIFICAR CÓDIGO

Estamos desarrollando **JJ Compra Inteligente**, una app mobile-first para Tenerife. El verde será el color dominante. La calidad visual es prioridad. En esta colaboración **Codex realiza toda la programación**; ChatGPT prepara el producto, las especificaciones y revisiones.

**IMPORTANTE: esta primera tarea es SOLO DE LECTURA Y DIAGNÓSTICO. No escribas código, no instales dependencias, no migres el proyecto ni hagas commits.**

1. Inspecciona el repositorio seleccionado: estructura, README, ramas, últimos cambios, dependencias, scripts de build/test, secretos expuestos si los hubiera, assets, pantallas y estado de la app. No compartas valores de secretos.
2. Enumera lo que YA existe y funciona, lo que está incompleto y lo que está ausente. No asumas que el repositorio está vacío.
3. Confirma la arquitectura real y si tiene sentido continuar sobre ella. Si es necesario un cambio mayor, ofrece opciones con ventajas, riesgos y costes, sin ejecutarlo.
4. Describe el estado de la interfaz actual y los problemas visuales concretos: tipografía, marca, colores, navegación, jerarquía, espaciados, accesibilidad, cargas y estados vacíos. Adjunta capturas SOLO si has podido ejecutar el proyecto; no inventes capturas.
5. Propón cómo integrar sin sobreescribir el kit de especificaciones: `AGENTS.md`, producto, dirección visual, pantallas, plan, decisiones y bloques B00–B09.
6. Presenta un plan de trabajo por PRs. El siguiente trabajo será **B01 Identidad Visual**, no el backend ni la IA.
7. Devuelve un informe estructurado: «Inventario», «Qué funciona», «Qué falta», «Riesgos», «Diseño actual», «Plan de integración de docs», «Plan de PRs», «Dudas que realmente bloquean».

**No empieces B01 hasta que aprobemos B00.** Mantén cualquier decisión dudosa como propuesta y no inventes acuerdos con supermercados, precios reales ni funciones existentes.
