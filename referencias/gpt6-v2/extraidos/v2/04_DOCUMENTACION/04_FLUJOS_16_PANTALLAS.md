# Flujos de navegación: 16 vistas

- **Bienvenida → Inicio**: empieza sin cuenta; 3D no activado por defecto.
- **Inicio → Mi compra → Buscar → Detalle → Revisar → Confirmar**: producto nunca se añade con cifras o unidades ambiguas.
- **Inicio → Voz / Escáner → Revisión editable → Confirmar**: el usuario decide; permisos opcionales.
- **Inicio → Menús → Detalle receta → Raciones → Ingredientes → Revisar qué falta → Mi compra**: deduplicar tras autorización explícita.
- **Ahorro → Presupuesto / Comparador / Historial**: precios y costes ausentes hasta verificación.
- **Perfil (avatar) → Hogar / Mis tiendas / Privacidad / Preferencias**: sin 5ª pestaña y modo local disponible.
- **Campana → Notificaciones**: sin alertas reales de ofertas si no hay fuentes conectadas.

## Rutas de vuelta
Todas las subpantallas deben mostrar navegación atrás; modales se cierran con cancelar y nunca pierden cambios no confirmados sin avisar.
