# B03 | Prototipo visual navegable de iPhone
**Estado inicial:** PENDIENTE | **Dependencia:** B02 aprobado.
**Objetivo:** ver y probar una app con aspecto terminado, sin confundir la maqueta con funcionalidades finales.

## Encargo a Codex
1. Implementar SOLO por Codex el prototipo visual de las 5 pantallas según el diseño aprobado, en la arquitectura existente del repo; no reconstruir el proyecto si no hace falta.
2. Permitir navegación básica entre pantallas y acciones simuladas claramente etiquetadas como demo.
3. Usar ejemplos locales controlados para representar listas/menús/estados; **nunca** simular acuerdos con tiendas o pagos completados.
4. Obtener screenshots de dispositivo iPhone (emulador/simulador o captura real) para cada pantalla y los estados críticos. Registrar dimensiones y método de captura.
5. Mostrar la aplicación en tamaño pequeño y grande; revisar teclado, safe area, gestos, texto grande y usabilidad con una mano.
6. Entregar pasos exactos de ejecución y dónde encontrar previews para revisarlos en iPhone.

## Entregables
PR de prototipo, imágenes reales de ejecución, evidencia de test visual y nota de qué pantallas son demo.

## Aceptación
- [ ] El diseño coincide con B02.
- [ ] Es navegable y no hay botones completamente muertos sin explicación.
- [ ] Se ve correctamente en iPhone pequeño/grande.
- [ ] Estados vacíos/error/cargando identificables.
- [ ] El propietario valida la experiencia antes de B04.

**STOP:** ninguna función compleja ni integración de pago hasta validación.
